# Yaqeen Data — بيانات تطبيق يقين

> 📜 **لو انت هنا علشان بتدوّر على «وصية التطبيق» أو ورثت المسؤولية عنه:**
> افتح ملف [CONTINUITY.md](CONTINUITY.md) — مكتوب بالعربي البسيط لغير التقنيين،
> وأول قسم فيه بيقولك تعمل إيه حتى لو مش فاهم في التكنولوجيا خالص.

بيانات ثابتة يقرأها تطبيق «يقين» عبر jsDelivr CDN مثبّتة على commit SHA — الهدف استمرارية التطبيق بلا أي سيرفر شخصي.

## fatwas/ — فتاوى الشيخ ابن باز رحمه الله

- **المصدر:** الموقع الرسمي للشيخ عبدالعزيز بن باز رحمه الله <https://binbaz.org.sa> — نقل حرفي بلا أي تعديل، وكل فتوى معها رابط أصلها.
- **المحتوى:** 10,171 فتوى في 161 تصنيفاً.
- `index.json` — الإجمالي والتصنيفات والمفتي والمصدر.
- `search.json` — فهرس البحث `[id, title, question≤240, category]`.
- `chunks/c{K}.json` — النصوص الكاملة، 100 فتوى لكل ملف (`K = floor(id/100)`).

> لا يُضاف لهذا المستودع أي محتوى مولَّد بالذكاء الاصطناعي — نقل مُسنَد فقط.
